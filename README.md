# Medical Data History — SQL Project

## 📌 Project Overview

This project focuses on analyzing medical data using SQL and MySQL.

The database contains information about patients, admissions, and doctors.
The project consists of 35 SQL queries covering data filtering, aggregation,
joins, grouping, string functions, date functions, conditional logic,
and calculated fields.

## 🛠️ Technologies Used

- MySQL
- SQL
- Docker

## 📚 SQL Concepts Practiced

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions
- JOIN
- UNION
- CASE
- String Functions
- Date Functions
- Conditional Aggregation
- Calculated Columns
